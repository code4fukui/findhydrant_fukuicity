# findhydrant_fukuicity

福井市の公式ポータルから提供されているオープンデータを活用し、市内の消火栓の位置を表示するウェブアプリケーションです。


![findhydrant_fukuicity ユーザーインターフェース](ss.jpg)


## 機能

-   **インタラクティブマップ:** [Leaflet](https://leafletjs.com/) を使用し、[国土地理院 (GSI)](https://maps.gsi.go.jp/development/ichiran.html) の地図タイルで消火栓の位置をマップ上に表示します。
-   **ジオロケーション:** ユーザーの位置を自動的に検出して、周辺の消火栓を表示します。
-   **最寄り消火栓の検索:** すべての消火栓までの距離を計算し、並べ替えます。「最寄り」ボタンを押すと、最も近い消火栓に即座にフォーカスします。
-   **並べ替えナビゲーション:** 「◀」および「▶」ボタンを使用して、距離が近い順に消火栓を閲覧できます。
-   **ダイナミックアイコン:** 水源の種別（例: 公設消火栓、私設消火栓、防火水槽、プール）に応じて、異なるアイコンを使用します。
-   **詳細情報:** 任意の
